# dsh-jev-context-gate

[English](README_en.md) | 简体中文

DSH 的 Jev 规则插件。选择独立判定模型后，按事件读取待判断内容、提出选择题，并执行获选选项配置的行为。普通模型使用 LLM JSON 估计选项概率；型号以 `jev-` 开头时标为 Jev 原生，原生结构化调用仍需模型提供商接入。

## 0.1.16

“Skill 裁剪”的保留数量直接在编辑弹窗的“最多保留多少条”中修改，例如从 10 改为 5。一次判定对候选项分别评分；最多 100 条候选为一批，超过时分批评分并对入围项复评，不为每个 Skill 单独发送一次请求。即使候选数量不超过保留数，也会按最低相关度筛选。

同一筛选能力也支持自定义内容：添加规则，事件选“用户发送消息”，判定方式选“筛选自定义候选”，每行输入一条注意事项，选择待判断内容、设置题目和“最多保留多少条”。入选内容会注入当前会话。候选来源也可改为“筛选脚本候选”；脚本每次事件发生时执行，可读取本机文件，返回字符串数组或 `{ id, text }` 数组。候选至少 2 条、最多 500 条，总内容不超过 64000 字；保留数量为 1–50。

## 0.1.15

规则列表直接显示标题和说明。点击“编辑”在独立弹窗中配置事件、待判断内容、题目和选项行为；弹窗内保存，取消会撤销本次编辑。旧规则缺少标题时，列表以说明作为名称，标题和说明都为空时显示“未命名规则”。

## 0.1.14

新增配置规则“Skill 裁剪”：事件为 Skill 目录准备注入，输入为当前可见会话上下文，题目为“与当前上下文最相关的 Skill 有哪些？”，候选选项由可用 Skill 的名称和简介动态生成，动作参数为保留数量 10。判定模型给候选项分别打相关度分数，主模型只收到保留的简介。标题、题目、输入、阈值和保留数量都可在规则里编辑；规则可关闭。前置规则的选项也可指定一个 Skill 名称，命中时由 DSH Skill 服务加载并注入其正文。另有“Skill 正文准备注入”事件：每次 Jev 准备注入自己选中的 Skill 时，按规则分别判断，可继续、跳过或附加上下文。用户显式调用的 Skill 保持原有宿主行为。

## 0.1.13

规则标题、规则说明和题目标题分别保存。收起的卡片显示规则标题与说明；编辑时一次只展开一条规则，选项动作内容按需展开，保存操作位于列表上方。旧规则没有标题时显示规则序号，可在编辑区补填。

## 0.1.11

规则页在浏览器接收到旧格式规则时先迁移再渲染，避免首屏短暂崩溃。

## 0.1.10

- 每条规则有独立开关和可编辑说明；收起时显示说明、题目与内容来源。编辑区按“事件 → 待判断内容 → 题目 → 选项与行为”紧凑排列，详细帮助按需展开。每个选项分别设置动作类型及文字参数，未选中的行为不会执行。
- 事件可选“用户发送消息”或“工具返回结果”。内容可选最新用户消息、当前步骤可见文本、本轮工具结果或自定义固定文字。运行时读取的内容在规则页说明。
- 题目可直接配置标题和选项，也可由自定义 JavaScript 生成标题和选项文案。脚本在本机工作线程执行，可自行读取文件，必须返回同一组选项 ID；脚本不能修改选项行为。
- Jev 有一个总开关。测试是规则页内的独立视图，由“打开测试页面”进入；测试不执行规则或修改会话。
- 旧规则在读取时迁移为“是/否”或“有失败/全部成功”的选项行为；旧前置、后置开关保留兼容字段，但不再控制运行。

## 规则语义

| 字段 | 可配置内容 | 运行时含义 |
| --- | --- | --- |
| 规则标题、规则说明 | 分别输入 | 用于识别和解释规则，不发送给判定模型 |
| 事件 | 用户发送消息、Skill 目录准备注入、Skill 正文准备注入、工具返回结果 | 前三个在 `agent/pre-step`，后者在含工具结果的 `llm/stream`；正文事件只处理 Jev 选中的 Skill |
| 待判断内容 | 下拉选择来源，或自定义文字 | 动态来源在事件发生时读取；自定义文字按原样使用 |
| 题目 | 直接配置或生成脚本 | 标题与 2–16 个选项一同发给判定模型 |
| 选项 | 文案、动作类型、动作参数 | 最高概率选项达到规则阈值后才执行该选项动作 |

前置动作“补充主会话上下文”会追加一条插件消息；“注入 Skill 正文”按选项中配置的名称加载。Skill 事件的“跳过此次 Skill 注入”只作用于当前候选 Skill；若启用了 Skill 事件规则但判定不可用，本次注入不执行。工具结果事件的动作“在答复末尾追加提醒”发生在原始流结束前，不会撤回已显示文字。判定失败、脚本失败、无事件内容、结果无效或超过上下文预算时不执行动作。普通模型概率是自报估计，不是校准置信度。

“Skill 裁剪”处理宿主注入的 Skill **简介目录**，不是批量加载 Skill 正文。目录规则判定失败时保留宿主原目录并写入警告；旧会话此前已记录的完整目录仍留在历史中，新会话首次注入即按规则裁剪。

## 题目脚本

脚本正文接收 `event`（`before`、`skill-catalog`、`skill-injection` 或 `after`）、`input`（本次待判断文字）和 `options`（`[{ id, label }]`）。它可以使用 `await import(...)` 和本机文件 API，须在 5 秒内返回：

```js
const fs = await import('node:fs/promises')
const extra = await fs.readFile('C:/rules/question.txt', 'utf8')
return {
  title: extra.trim() + '：这条消息需要调查吗？',
  options: options.map(option => ({ id: option.id, label: option.label })),
}
```

脚本在独立工作线程运行，但拥有本机 Node 权限；仅配置自己信任的代码。输出只能改变标题和选项文案，动作始终来自已保存规则。

## 开发与发布

```powershell
npm run check
npm pack --dry-run
```

发布顺序：提交并推送源码和版本标签 → 确认远端 SHA → 更新私有 `plugins.json` 中的固定 SHA 与版本 → Import → 重启 DSH → 回读安装包和浏览器交互。不要用 `link:`、`file:` 或 `workspace:` 作为安装源。

## 限制

Jev 原生结构化调用尚未接入；普通模型返回的概率未经校准。追加提醒不能阻止此前已经流式显示的文字。插件不会验证模型给出的事实结论。
