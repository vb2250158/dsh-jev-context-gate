# dsh-jev-context-gate

[English](README_en.md) | 简体中文

独立开源 DSH 插件：在用户消息进入主模型前，按数据驱动规则决定是否注入“先调查再结论”等上下文；在模型流阶段提供证据约束扩展点，减少“没调查就瞎猜”。不依赖 RabiRoute、Manager、人格、计划或任何业务资料库。

## 当前状态

`0.1.0` 是第一版开发基线：规则解释器、结构化普通模型判定、前置注入、DSH settings 命名空间、Jev 设置菜单、模型目录选择、规则 JSON 编辑和宿主证据约束纯函数已实现。真实 Jev provider 协议、设置页真实模型测试、后置流接线和完整 DSH 组合验收仍在实现中。未完成部分不会显示为“已确认”。

## 设计

- **前置**：使用公开 `agent/pre-step`，只追加插件预设的上下文。模型返回内容不能变成脚本、权限或动态 prompt。
- **后置**：使用公开 `llm/stream` 作为最终答复流的唯一可替换边界；`turn-stopping` 和 `session/event` 不能阻止已经显示或提交的文字。
- **数据驱动**：每条规则有 `id`、阶段、问题、阈值和预设上下文。结果只负责命中/不命中；注入文本由用户配置且经过长度边界。
- **Jev 模式**：Jev 原生结构化输出和普通模型 JSON 输出分开标记；普通模型的自报概率不自动称为校准 confidence。

## 设置与测试

设置中新增“Jev”页，可开关前置/后置阶段、调整上下文预算和纠偏上限。Jev 测试允许输入文字和阶段，显示规则预览；默认不会注入真实会话，也不会执行工具。模型选择器接入 DSH 模型目录的下一步实现会保持 provider/model 为独立配置，不改变主会话模型。

## 开发

```powershell
npm test
npm run build
npm run check
npm pack --dry-run
```

发布前先测试和构建，再 `git add -A`、提交、打版本 tag、推送分支和 tag；确认远端 SHA 后再更新 DSH 私有清单。不要使用 `link:`、`file:` 或 `workspace:` 作为安装源。

## 限制

这是防止未经调查的确定性结论的辅助门禁，不是事实校验器。没有源码、配置、日志或运行复现证据时，插件只能约束措辞和推进调查，不能证明模型结论正确。
