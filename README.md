# dsh-jev-context-gate

[English](README_en.md) | 简体中文

独立开源 DSH 插件：在用户消息进入主模型前，按数据驱动规则决定是否注入“先调查再结论”等上下文；在模型流阶段提供证据约束扩展点，减少“没调查就瞎猜”。不依赖 RabiRoute、Manager、人格、计划或任何业务资料库。

## 当前状态

`0.1.9` 在选择题出结果后自动定位结果卡片，并明确提示 Jev 原生调用仍需模型提供商适配。

`0.1.8` 按 DSH 的 `finish.reason.kind` 流协议识别模型正常结束，修复真实测试误报失败。

`0.1.7` 增加普通模型选择题测试：题目、选项、各选项概率和分布集中度结果；模型型号自动区分 Jev 原生与 LLM JSON 模拟，移除手动模式开关。`0.1.6` 将默认规则改为中文，并用可折叠的规则卡片替代 JSON 编辑。规则解释器、普通模型判定、前置注入、DSH settings 命名空间、Jev 设置菜单、模型目录选择、规则表单和宿主证据约束纯函数已实现。Jev 原生结构化接口尚需模型提供商接入；普通模型测试可用已配置的 DSH 模型。后置流现在只对宿主 `tool-result` 失败事实追加有界提醒，并保留原始流；它仍不是已显示文字之前的绝对拦截。

## 设计

- **前置**：使用公开 `agent/pre-step`，只追加插件预设的上下文。模型返回内容不能变成脚本、权限或动态 prompt。
- **后置**：使用公开 `llm/stream` 作为最终答复流的唯一可替换边界；`turn-stopping` 和 `session/event` 不能阻止已经显示或提交的文字。
- **数据驱动**：每条规则有 `id`、阶段、问题、阈值和预设上下文。结果只负责命中/不命中；注入文本由用户配置且经过长度边界。
- **Jev 模式**：Jev 原生结构化输出和普通模型 JSON 输出分开标记；普通模型的自报概率不自动称为校准 confidence。

## 设置与测试

设置中新增“Jev”页。先选择判定模型，再输入待判断内容、题目和 2–16 个选项；普通模型测试会调用该模型并显示每个选项的估计概率、被选选项和按概率分布计算的模拟置信度。模拟置信度不是 Jev 的校准置信度。型号以 `jev-` 开头时自动标为 Jev 原生；原生结构化接口由后续模型提供商接入，当前不会伪装为普通模型测试。页面还可开关门禁和前置判定，并在规则卡片中修改启停、阶段、问题、注入内容与百分比阈值。规则修改需点击“保存规则”；放弃修改可恢复已保存版本。后置规则标记为暂未生效。

## 开发

```powershell
npm test
npm run build
npm run check
npm pack --dry-run
```

发布前先测试和构建，再 `git add -A`、提交、打版本 tag、推送分支和 tag；确认远端 SHA 后再更新 DSH 私有清单。不要使用 `link:`、`file:` 或 `workspace:` 作为安装源。

## 限制

这是防止未经调查的确定性结论的辅助门禁，不是事实校验器。没有源码、配置、日志或运行复现证据时，插件只能约束措辞和推进调查，不能证明模型结论正确。
